THE CROCHET AURA — WEBSITE DEMO

HOW TO USE IN ACODE
1. Extract The-Crochet-Aura-Website.zip.
2. Open the extracted folder in Acode.
3. Open index.html and use Preview / browser preview.

FILES
- index.html: website structure and brand content
- style.css: responsive styling and CSS-only decorative artwork
- app.js: mobile navigation and footer year
- assets/crochet-aura-logo.png: cropped original logo from the supplied screenshot

BRAND DETAILS USED
- Name: The Crochet Aura
- Instagram handle: @thecrochetaura.in
- Location: Amritsar, India
- Products/services described in profile: crochet bouquets, flowers and gifts
- Shipping: worldwide
- Bulk orders: available
- Orders: Instagram DM

IMAGE NOTE
Only the supplied brand logo is used as an image. No product photos have been inserted.
The decorative collection illustrations are made with CSS and are not representations of actual products.

DEMO LIMITATIONS
This is a front-end website demo. Online checkout, inventory, order storage and payment processing
are not connected. The Instagram contact links open the profile shown in the supplied screenshot.
